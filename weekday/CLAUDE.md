# Weekday - game

A game where the player has to guess the weekday of a random date choosen by the game.

The player can set a time range (with two date pickers: beginning and end).

The game choose a random date and asks the player for the weekday of that date. The player has 7 buttons with the 7 weekday names and have to choose. The game goes on and on until the player hits an "End" button.

The game continuely shows: (how many guesses the player made during the session, how many times they guessed right and wrong, the total time, the minimum time, the maximum time.

There is a start button (that becomes the end button, when the game is started).

If you inspect the project, you'll see there are already 2 games. This is a third one.
