# mini-games

Hosted at [mugnozzo.xyz/mini-games](https://mugnozzo.xyz/mini-games).

A place to host some mini-games I make for my children.

## pixel-art
A simple pixel art canvas with some functions like zoom, fill, adjust brush size, clear canvas, and the possibility to save the project as a JSON file or the image in PNG.

Play it [here](https://mugnozzo.xyz/mini-games/pixel-art)!

## weekday
Guess the day of the week of a random date. Choose a date range, press Start, and pick the right weekday as many times as you like; the game keeps track of right/wrong guesses and your fastest, slowest and total time.

Play it [here](https://mugnozzo.xyz/mini-games/weekday)!
